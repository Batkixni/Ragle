01 · Core Features

核心功能與原生架構介紹

Raglex 以 Go + MyGo 與嵌入式 bbolt 資料庫打造，徹底避開 Electron 的記憶體與啟動開銷，專注於「檔案自主權、離線 AI 搜圖、無限參考白板與完全可自架同步」。

1. 原生極速效能與跨平台體驗

  • 單一 ~21 MB 原生執行檔：無瀏覽器核心負擔，冷啟動不到 1 秒，支援 Windows 11 Acrylic、macOS Vibrancy 原生視窗按鈕與 Linux 桌面。
  • 萬筆圖庫視窗虛擬化：素材網格與白板托盤皆採虛擬化渲染，面對數萬張設計素材依然維持高幀率捲動。

2. 四種非破壞性存放模式（預設「索引不複製」）

存放模式磁碟行為刪除時預設行為
Index（預設）完全不複製、不搬動原檔，直接索引你的原始資料夾僅移除資料庫紀錄；可於刪除彈窗明確勾選「同時永久刪除實體檔案」
Symlink於資料庫建立系統捷徑連結指向原檔僅移除連結；勾選永久刪除時一併移除目標檔案
Copy複製一份獨立副本至資料庫目錄，原檔不受影響僅移除資料庫副本，保留原本外部檔案
Move將檔案移入資料庫統一託管永久移除資料庫內該檔案（刪除前會顯示明確警告）

3. 本機視覺 AI Embedding、OKLab 色票與離線自動分類

  • 本機視覺 AI Embedding：完全在你的電腦本機計算圖片特徵向量與感知雜湊，不需連網即可進行「以圖搜圖」與「尋找相似風格／構圖素材」。
  • OKLab 主色票提取：匯入時自動計算 5 組代表色，右側資訊欄點擊色點即可複製 HEX，搜尋列可直接按色系篩選。
  • 本機 Ollama / Laya 智慧標籤（選配）：在偏好設定填入本機端點 URL 與視覺模型名稱，即可獲得非侵入式標籤建議，完全不經過第三方 API。

4. 無限參考白板 & 永遠置頂浮動參考視窗

  • 支援自由縮放平移、圖片排列、多選對齊、群組、畫框（Frame）、手繪標記筆、箭頭與多行文字筆記。
  • 可將任一白板彈出為永遠置頂半透明參考視窗（可調透明度、縮放、灰階切換），配合 Blender、Photoshop、Figma、Clip Studio 使用。

5. 平行資料夾、階層標籤、版本堆疊、全媒體與插件市集

  • 整理工具：平行階層資料夾、8 色繼承標籤樹、版本堆疊（Stacks）、監控資料夾（Watch Folders）自動匯入、規則式批次重新命名（含衝突預覽與復原）。
  • 全媒體預覽：圖片、影片（隨附靜態 ffmpeg）、相機 RAW（CR3/ARW/NEF/RAF/NAF/DNG）、SVG、字型、音訊與 PDF。
  • 開放插件系統：透過標準 stdin/stdout JSON 協議支援任何程式語言，內建社群 PR 市集 Batkixni/raglex-plugins（包含 Eagle Import、重複素材掃描、色票匯出器等外掛）。

Core Features & Native Architecture

Built with Go + MyGo and embedded bbolt, Raglex eliminates Electron overhead and centers around file ownership, offline visual AI search, infinite moodboards, and self-hosted E2EE sync.

1. 100% Native Speed Across Platforms

  • Single ~21 MB native executable: Instant cold start and minimal RAM footprint, tailored for Windows 11 Acrylic, macOS Vibrancy & native traffic lights, and Linux.
  • Viewport Virtualization: Both the library grid and board library tray virtualize rendering so 10,000+ asset collections stay responsive.

2. Four Storage Modes (Non-Destructive Index by Default)

ModeDisk BehaviorDefault Delete Behavior
Index (Default)Never copies or moves files — indexes folders in placeRemoves DB index only; explicit opt-in checkbox available for permanent disk deletion
SymlinkCreates a symlink inside the library pointing to your fileRemoves symlink only; permanent checkbox also deletes the target regular file
CopyCopies an independent file into the library folderDeletes the library copy only; external original stays untouched
MoveMoves the file into the library folderPermanently removes the moved file (with clear danger warning)

3. On-Device Visual AI Embedding, OKLab Palette & Local Auto-Tagging

  • Local Visual AI Embedding: Computes image feature vectors and perceptual hashes locally for instant Search by Image and visual similarity search — 100% offline.
  • OKLab Dominant Palette: Automatically extracts 5 dominant swatches per asset; click any swatch in the Inspector to copy HEX or filter your library by color.
  • Optional Local Ollama / Laya Vision Tagging: Connect your own local vision model to generate non-intrusive tag suggestions without sending data to cloud APIs.

4. Infinite Reference Boards & Always-on-Top Floating Window

  • GPU-accelerated freeform moodboards supporting groups, frames, freehand strokes, arrows, and multiline text notes.
  • Pop out any board into a translucent always-on-top floating reference window with opacity, zoom, and grayscale controls over Blender, Photoshop, Figma, or Clip Studio.

5. Organization, Creative Media & Open Plugin Marketplace

  • Workflow: Parallel hierarchical folders, 8-color inherited tags, version stacks, Watch Folders, and rule-based Batch Rename with conflict preview & undo.
  • Media: Images, video (with bundled static ffmpeg), Camera RAW (CR3/ARW/NEF/RAF/NAF/DNG), SVG, fonts, audio, and PDFs.
  • Plugin Marketplace: Any-language stdin/stdout JSON plugins distributed via Batkixni/raglex-plugins (including Eagle Import, Smart Duplicate Finder, Color Palette Exporter, Auto Aspect Tagger, and more).

コア機能とネイティブ設計

Go + MyGo と組み込み bbolt による純ネイティブ構成。Electron の重さを排除し、ファイル所有権・ローカル視覚 AI 検索・無限ボード・Self-Host 暗号化同期を軸に設計されています。

1. 100% ネイティブ高速動作

  • 約 21 MB の単一ネイティブバイナリ：瞬時に起動し、省メモリで動作。Windows 11 Acrylic、macOS Vibrancy＆ネイティブボタン、Linux に対応。
  • ビューポート仮想化：ライブラリ一覧・ボード内トレイともに仮想化レンダリングを採用し、数万件の素材でも滑らかに動作します。

2. 4 種類の保存方式（デフォルトはコピー不要の Index）

方式ディスク上の動作削除時のデフォルト動作
Index（初期設定）元ファイルを複製・移動せずその場で管理DB 記録のみ削除。完全削除したい場合のみモーダル内で明示チェック可能
Symlinkライブラリ内に元ファイルへのリンクを作成リンクのみ削除（完全削除チェック時は実ファイルも削除）
Copyライブラリ内に独立コピーを作成ライブラリ内コピーのみ削除し、外部の元ファイルは保持
Moveファイルをライブラリへ移動移動済みファイルを完全削除（警告表示あり）

3. ローカル視覚 AI Embedding・OKLab パレット・自動タグ

  • 端末内視覚 AI Embedding：特徴ベクトルと知覚ハッシュを完全オフラインで計算し、類似画像検索や画像からの検索を高速に実行。
  • OKLab 5 色パレット：代表色を自動抽出し、ワンクリックで HEX コピーや色調フィルタが可能。
  • ローカル Ollama / Laya 連携（任意）：自宅 PC 上のビジョンモデルと接続し、外部クラウドへ送信せずにタグ候補を提案します。

4. 無限リファレンスボード & 最前面フローティング参照窓

  • グループ、フレーム、フリーハンド描画、矢印、複数行メモに対応した GPU 高速化キャンバス。
  • 不透明度・ズーム・グレースケール切替を備えた 最前面フローティング参照ウィンドウ で制作ソフトの上に常駐表示できます。

5. 並列フォルダ・階層タグ・クリエイティブ形式・プラグイン市場

  • 並列階層フォルダ、8 色継承タグ、バージョンスタック、監視フォルダ、プレビュー＆元に戻す付き一括リネームを搭載。
  • 画像・静的 ffmpeg 同梱動画・カメラ RAW・SVG・フォント・音声・PDF をネイティブ表示。
  • あらゆる言語で書ける stdin/stdout JSON プラグイン規格と公開レジストリ Batkixni/raglex-plugins に対応。
02 · Self-Host Sync Server

Self-Host 自架端對端加密同步伺服器

在自家 NAS、家用伺服器或 VPS 用一行 Docker 指令部署開源的 raglex-server，搭配 Raglex 預設開啟的 AES-256-GCM 零知識端對端加密，在多台電腦與手機間完全自主同步。

Self-Hosting Your Own E2EE Sync Server

Run the open-source raglex-server on your NAS, home server, or VPS in a single Docker command — combined with Raglex's default-ON AES-256-GCM Zero-Knowledge E2EE for private multi-device sync.

Self-Host E2E 暗号化同期サーバー構築ガイド

自宅 NAS・ホームサーバー・VPS にオープンソースの raglex-server を Docker 1 コマンドで構築し、デフォルト有効の AES-256-GCM ゼロ知識 E2E 暗号化 で安全にマルチデバイス同期できます。

方式一：Docker Compose 一鍵啟動（推薦）

macOS / Linux (Bash) 
git clone https://github.com/Batkixni/Raglex.git
cd Raglex/deploy
export RAGLEX_TOKEN="$(openssl rand -hex 32)"
docker compose up -d
Windows (PowerShell) 
git clone https://github.com/Batkixni/Raglex.git
cd Raglex\deploy
$env:RAGLEX_TOKEN = -join ((1..32) | ForEach-Object { "{0:x2}" -f (Get-Random -Maximum 256) })
docker compose up -d

方式二：獨立執行檔（免 Docker）

raglex-server CLI 
./raglex-server -addr ":47595" -library "/var/lib/raglex" -token "your-strong-secret-token"

HTTPS 反向代理範例（Caddy / Nginx）

Caddyfile 
sync.yourdomain.com {
    reverse_proxy 127.0.0.1:47595
}
Nginx 
server {
    listen 443 ssl http2;
    server_name sync.yourdomain.com;
    client_max_body_size 512M;

    location / {
        proxy_pass http://127.0.0.1:47595;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 900s;
        proxy_send_timeout 900s;
    }
}

選配：串接 Cloudflare R2 / S3 / MinIO 物件儲存

deploy/docker-compose.yml (environment) 
RAGLEX_S3_ENDPOINT: "https://<account-id>.r2.cloudflarestorage.com"
RAGLEX_S3_BUCKET: "raglex-blobs"
RAGLEX_S3_REGION: "auto"
RAGLEX_S3_ACCESS_KEY: "<access-key>"
RAGLEX_S3_SECRET_KEY: "<secret-key>"

在桌面端連線與備份 AES-256 端對端加密金鑰

1

填入自架伺服器連線資訊

開啟 偏好設定 → 帳號與同步 → Self-Host，填入你的伺服器網址（如 https://sync.yourdomain.com 或內網 http://<IP>:47595）與 RAGLEX_TOKEN。

2

備份自動產生的 256-bit 隨機 AES 金鑰

前往 偏好設定 → 同步與協作，端對端加密（AES-256-GCM）已預設開啟並自動產生 rglx-aes256-... 隨機金鑰。點擊 另存金鑰檔（儲存 raglex-e2ee-key-*.txt）或 複製 妥善保存。

3

在第二台裝置載入金鑰解密還原

在另一台電腦同樣輸入伺服器網址與 Token 後，點選 載入金鑰檔（或貼上金鑰），即可自動解密並雙向增量同步；你也可以逐一勾選要同步哪些資料夾。

1

Enter Your Self-Host Server Details

Open Preferences → Account / Sync → Self-Host and enter your server URL (e.g. https://sync.yourdomain.com or LAN http://<IP>:47595) plus your RAGLEX_TOKEN.

2

Back Up Your Auto-Generated AES-256 Key

Under Preferences → Sync & Collab, End-to-End Encryption (AES-256-GCM) is ON by default with a random rglx-aes256-... key. Click Save Key File or Copy to back it up safely.

3

Load the Key on Your Second Device

Enter the same Server URL and Token on your second computer, click Load Key File (or paste the key), and start syncing. Use Selective Folder Sync to choose which folders sync.

1

Self-Host サーバー情報を入力

環境設定 → アカウント / 同期 → Self-Host を開き、サーバー URL（例：https://sync.yourdomain.com）と RAGLEX_TOKEN を入力します。

2

自動生成された AES-256 キーをバックアップ

環境設定 → 同期とコラボ では エンドツーエンド暗号化 (AES-256-GCM) が初期設定で有効になっており、rglx-aes256-... キーが自動生成されます。キーを保存 または コピー で安全に保管してください。

3

別の端末でキーを読み込んで復号同期

2 台目の端末でも同じサーバー URL とトークンを設定し、キーを読み込む から保存したファイルを読み込めば自動的に復号・差分同期が始まります。

03 · Browser Companion Extension

瀏覽器擴充安裝與使用教學

支援 Chrome、Edge、Brave、Arc、Firefox 與 Zen Browser。右鍵一鍵存圖並記錄來源網址，亦可批次收集整頁圖片，並支援 Raglex 未開啟時自動落盤至「離線收件資料夾」。

1

啟動本機伺服器並複製 Access Key

開啟 Raglex → 偏好設定 → 分享 / 進階，啟用 內建本機伺服器（預設 Port 47595，僅綁定本機 127.0.0.1），建議勾選開機自動啟動，並點擊 複製存取金鑰（Access Key）。

2

安裝擴充套件（Chrome / Edge / Brave / Arc）

從 GitHub Releases 下載 raglex-browser-extension.zip 並解壓縮到固定資料夾 → 打開 chrome://extensions（Edge 為 edge://extensions）→ 開啟右上角 開發人員模式 → 點擊 載入未封裝項目 選擇剛解壓縮的資料夾。

3

安裝擴充套件（Firefox / Zen Browser）

從 Releases 下載 raglex-firefox-extension.xpi，拖曳進瀏覽器視窗即可安裝（Developer Edition / Nightly / Zen 需於 about:config 設 xpinstall.signatures.required = false）；正式版 Firefox 可於 about:debugging#/runtime/this-firefox 載入臨時附加元件。

4

貼上 Access Key 完成配對 & 設定離線收件匣

點開工具列上的 Raglex 圖示，確認網址為 http://127.0.0.1:47595 並貼上 Access Key 看到綠燈連線即完成。若想在沒開 Raglex 時也能存圖，請在 偏好設定 → 匯入 設定「離線收件資料夾」（如 ~/Downloads/RaglexInbox），下次開啟 Raglex 會自動將圖片與來源資訊全部匯入！

Browser Companion Extension Guide

Clip inspiration straight from Chrome, Edge, Brave, Arc, Firefox, or Zen Browser with source URL & page title, batch-collect page images, or capture offline into your Clipper Inbox even when Raglex is closed.

1

Enable Built-in Local Server & Copy Access Key

Open Raglex → Preferences → Sharing / Advanced, turn on Built-in Local Server (default port 47595 on 127.0.0.1), optionally enable Auto-Start, and click Copy Access Key.

2

Install on Chrome / Edge / Brave / Arc

Download raglex-browser-extension.zip from GitHub Releases and unzip it to a permanent folder → open chrome://extensions (or edge://extensions) → enable Developer mode → click Load unpacked and select the unzipped folder.

3

Install on Firefox / Zen Browser

Download raglex-firefox-extension.xpi and drag it into the browser window (on Zen / Developer Edition / Nightly with xpinstall.signatures.required = false in about:config), or load manifest.json via about:debugging#/runtime/this-firefox.

4

Pair with Access Key & Optional Offline Inbox

Click the Raglex toolbar icon, confirm http://127.0.0.1:47595, and paste your Access Key until the status turns green. To clip while Raglex is closed, configure an Offline Clipper Inbox folder (e.g. ~/Downloads/RaglexInbox) under Preferences → Import.

ブラウザ拡張機能のインストールと使い方

Chrome・Edge・Brave・Arc・Firefox・Zen Browser に対応。右クリック保存やページ内画像の一括収集に加え、Raglex 未起動時でも保存できるオフライン受信トレイを備えています。

1

ローカルサーバーを有効化し Access Key をコピー

Raglex → 環境設定 → 共有 / 詳細 で 内蔵ローカルサーバー（既定ポート 47595）をオンにし、アクセスキーをコピー します。

2

Chrome / Edge / Brave / Arc に導入

GitHub Releases から raglex-browser-extension.zip をダウンロードして展開 → chrome://extensions（Edge は edge://extensions）を開く → デベロッパーモード を有効化 → パッケージ化されていない拡張機能を読み込む で展開フォルダを選択。

3

Firefox / Zen Browser に導入

raglex-firefox-extension.xpi をダウンロードしてウィンドウへドラッグ＆ドロップ（Zen / Developer Edition では about:config の xpinstall.signatures.required = false）、または about:debugging#/runtime/this-firefox から読み込みます。

4

Access Key を貼り付けて接続 ＆ オフライン受信設定

ツールバーの拡張アイコンを開き、http://127.0.0.1:47595 とコピーした Access Key を入力すると接続完了。環境設定 → 取り込み でオフライン受信フォルダを指定すると、Raglex を閉じていても画像を保存し次回起動時に自動取り込みできます。
