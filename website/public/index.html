編譯為約 21 MB 單一原生執行檔搭配嵌入式 bbolt，秒開不卡頓、極低記憶體占用。內建視窗虛擬化，面對數萬筆圖庫照樣 120Hz 絲滑捲動；深度貼合 Windows 11 Acrylic、macOS Vibrancy 原生紅黃綠按鈕與 Linux 桌面。

索引不複製，檔案永遠屬於你

預設「索引（Index）」模式原地讀取你的硬碟資料夾，絕不重複複製佔空間、零專屬格式鎖死。同時支援 Symlink / Copy / Move 策略，刪除時預設保留原檔並可明確勾選「永久刪除實體檔案」。

本機視覺 AI Embedding & 色票搜圖

完全離線計算圖片視覺特徵向量與感知雜湊，直接「以圖搜圖」與尋找相似構圖；自動提取 5 色 OKLab 主色票，亦可選配本機 Ollama / Laya 視覺模型自動建議標籤，素材不外傳。

AI Embedding OKLab Palette Ollama / Laya

無限參考白板 & 永遠置頂浮動參考窗

GPU 加速無限自由畫布，支援圖片排版、群組、畫框（Frame）、手繪標記筆、箭頭與多行文字筆記；一鍵彈出半透明置頂浮動參考窗（支援透明度、縮放與灰階檢視），搭配 Blender / Photoshop / Figma / Clip Studio 創作零切換干擾。

Infinite Canvas Always-on-Top Grayscale Toggle

瀏覽器擴充 & 離線收件資料夾

支援 Chrome、Edge、Brave、Arc、Firefox 與 Zen Browser。右鍵單張存圖或批次掃描整頁圖片，自動保留來源網址與標題；就算沒開 Raglex，也能先存入離線收件資料夾，下次開啟自動匯入。

Self-Host 零知識 AES-256 端對端加密同步

一行 Docker 指令在自家 NAS 或 VPS 架設開源同步伺服器（支援 R2 / S3、手機 PWA、MCP）。端對端加密預設開啟並自動產生 256-bit 隨機 AES 金鑰（可另存／載入金鑰檔），搭配選擇性資料夾同步與 6 碼 P2P 跨裝置傳檔。

平行資料夾、階層標籤與全媒體原生預覽

平行階層資料夾、8 色繼承標籤樹、版本堆疊（Stacks）、監控資料夾自動匯入、規則式批次重新命名。原生支援圖片、內建靜態 ffmpeg 影片、相機 RAW（CR3/ARW/NEF/RAF/DNG）、SVG、字型、音訊與 PDF。
