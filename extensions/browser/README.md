# Raglex Web Clipper (Chromium — Manifest V3)

Collect visual bookmarks, YouTube / oEmbed / JSON-LD sources, screenshots, and page images directly into your local **Raglex** library, projects, and boards.

## Quick Setup (Chrome / Edge / Brave)
1. Open **Raglex** desktop and turn ON **Web & Mobile** under **Preferences → Sharing** (if an Access Key is configured, copy it from **Advanced Network**).
2. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select this `extensions/browser/` folder.
3. Click the **Raglex** toolbar icon — it connects automatically (`Connected`). Open the top-right **⚙ Settings** icon only if you need to enter an Access Key or adjust preferences.

## Features
- **Save Page (Bookmark / Source)**: 1-click capture for YouTube HD covers, oEmbed / JSON-LD multi-image galleries (auto-stacked), RSS/Atom feeds, or clickable visual web bookmarks.
- **Direct Destination Routing**: Clip straight into any **Tag**, **Project**, or **Board**, with optional notes.
- **Capture Screenshot**: Save the visible tab into Raglex as a crisp PNG.
- **Batch Page Grabber & Auto-Stack**: Scan images (including CSS background heroes) with resolution badges and optionally fold all grabbed images into a single Version Stack.
- **Drag-to-Save Capsule**: Drag any webpage image onto the bottom frosted-glass pill to save instantly.
