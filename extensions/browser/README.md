# Ragle Web Clipper (Browser Extension — Manifest V3)

Collect images, drag-and-drop visual references, capture screenshots, and batch-grab high-resolution galleries directly into your local **Ragle** library.

## Quick Setup (Chrome / Edge / Brave)
1. In **Ragle**, open **Preferences → Sharing** and turn ON **Run built-in server** (default `http://127.0.0.1:41595`), then copy your **API Token**.
2. In Chrome/Edge, open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select this `extensions/browser/` folder.
3. Click the **Ragle Web Clipper** toolbar icon, paste your API Token, and verify **Connected**.

## Features
- **Drag-to-Save**: Drag any image on a webpage to reveal the bottom-center `#FF5C33` Ragle drop capsule.
- **Right-click Menu**: *Save Image to Ragle* or *Capture Screenshot to Ragle* (automatically preserves Source URL & Page Title).
- **Batch Page Grabber**: Click **Scan Page Images** in the popup to pick multiple high-resolution images from Behance, ArtStation, Pixiv, Pinterest, or any site.
